# cortex-game

This project uses the [Cortex Command Community Project](https://github.com/cortex-command-community/Cortex-Command-Community-Project) as a submodule.

## Getting Started

Clone the repository with submodules:

```bash
git clone --recurse-submodules https://github.com/rs-v/cortex-game.git
```

Or, if you have already cloned the repository:

```bash
git submodule update --init --recursive
```
